# 🧑‍💻 Cline Bangla

**Bangla rules for your AI coding assistant in VS Code — it talks Bangla, works in small steps, never fakes code.**

## ✨ Features

- `.clinerules` — project rules in Bangla. Cline reads `.clinerules` files automatically (VS Code extension, JetBrains plugin and CLI) and follows them in every task.
- Bangla conversation, small steps, no placeholder code, no secrets in code, ask before adding libraries.

## 🚀 How to use

1. Install Cline from the VS Code Marketplace (`saoudrizwan.claude-dev`) or the JetBrains Marketplace.
2. Copy `.clinerules` into your project's root folder.
3. Open Cline in VS Code and write your task in Bangla — it will answer in Bangla and explain each change in Bangla, while keeping code and comments in English.

## ⚠️ Honest limits

- The rules apply per project — the file must sit in the project's root folder to be picked up.
- The model and provider key come from your own Cline setup; this repo only adds the Bangla rules, not the model.
- Rules guide the assistant — they cannot guarantee it never makes a mistake. Review every change.
